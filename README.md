# Computer Vision Projects

This repository contains five Computer Vision projects developed using
Python, OpenCV, Machine Learning and Deep Learning techniques.

## Projects

### 1. Fruit Quality Inspection System

Computer vision based inspection of fruit quality and visible defects.

### 2. Smart Parking Space Detection

Detection and classification of available and occupied parking spaces.

### 3. Road Lane Detection and Departure Warning

Detection of road lanes and identification of possible lane departure.

### 4. Real-Time Fire and Smoke Detection

Real-time detection of fire and smoke using computer vision and deep learning.

### 5. Vision-Based Waste Detection and Classification

Detection and classification of different types of waste using computer vision.

## Technologies

- Python
- OpenCV
- NumPy
- Matplotlib
- Pandas
- Scikit-learn
- YOLO
- PyTorch
